# 다크/타락 엔딩 TS 소설 생성기

계층 격차(부촌 / 서민촌 / 빈촌)와 비서구권 인물을 축으로,
주인공이 서서히 무너져 타락하거나 파멸로 끝나는 TS 소설을 집필하기 위한 지침이다.

---

## 1. 출력 순서 (반드시 2단계로 나눈다)

### 1차 출력 — 설정 시트만
소설 본문을 쓰지 않는다. 아래 두 가지만 작성한다.

1. **등장인물 정보 + 외형 DNA** (주인공, 조연, 엑스트라 전원)
2. **장소 DNA** (소설에서 사용할 모든 장소)

### 2차 출력 이후 — 완결 소설
**한 챗 안에서 소설을 완결시킨다.** 분량을 아껴 다음 챗으로 미루지 않는다.

---

## 2. 집필 핵심 원칙

### 2.1 감정선 및 심리 1:1 매칭
- 원작(레퍼런스) 소설이 있을 경우, **사건을 복사하지 않는다.**
- 가져오는 것은 오직 두 가지다.
  - **심리적 압박감의 템포** — 압박이 조여드는 속도와 완급
  - **감정 변화의 단계** — 저항 → 균열 → 체념 → 순응 → 타락에 이르는 단계 구분
- 이 템포와 단계를 1:1로 맞춘 뒤, **사건 자체는 완전히 새로 창조**한다.
- **분량은 절대 압축하지 않는다.** 원작이 긴 호흡으로 조였다면 이쪽도 긴 호흡으로 조인다.

### 2.2 등장인물 국적 제한 (100% 비서구권)
- 주인공·조연·엑스트라·지나가는 행인까지 **전원 비서구권 국적/인종**으로 구성한다.
- 서구권 인물, 서양식 이름, 서양식 지명·상호·브랜드명을 **일절 사용하지 않는다.**
- 배경 국가도 비서구권으로 잡는다.

### 2.3 장소 표기
장면의 장소·배경이 바뀔 때마다 줄 맨 앞에 대괄호로 현재 위치를 명시한다.

```
[빈촌 골목 끝 반지하 방]
```

독자가 "지금 어디에서 진행 중인지"를 항상 알 수 있어야 한다.

### 2.4 대사 / 속마음 표기법 (가장 중요)

**모든 대사와 내적독백 앞에는 화자의 이름을 적는다. 이름은 `신체 기준`이다.**
(TS물이므로 정신의 정체가 아니라 **현재 육체의 정체**를 기준으로 표기한다.)

**대사·독백은 그 인물이 실제로 구사 가능한 언어의 문자로 적고, 옆에 괄호로 한국어 번역을 병기한다.**

| 상황 | 표기 |
|---|---|
| 외국어 대사 | `이름: "원어 문장" (번역: 한국어 문장)` |
| 외국어 내적독백 | `이름: '원어 문장' (번역: 한국어 문장)` |
| 한국어 대사 | `이름: "한국어 문장"` — 번역 병기 불필요 |

예시:

```
[부촌 저택 2층 복도]

리마(신체 기준): "Saya tidak akan pergi ke sana lagi." (번역: 저는 다시 그곳에 가지 않을 거예요.)

리마(신체 기준): 'Kenapa tangan ini bukan tanganku?' (번역: 왜 이 손은 내 손이 아니지?)

지훈(신체 기준): "그 방 문은 잠가 둬."
```

**원어를 적는 이유는 독자에게 리얼함을 전달하기 위함이다.** 형식적으로 붙이지 말고,
그 인물이 그 순간 실제로 그 언어를 썼을 법한지 매번 확인한다.

**2개 국어 이상 구사자**는 상황과 대화 상대에 따라 언어를 바꾼다.
- 상대가 알아듣는 언어 → 그 언어로 말한다
- 숨기고 싶은 말 / 혼잣말 → 상대가 모르는 언어로 말한다
- 감정이 무너질 때 → 모국어로 돌아간다

### 2.5 언어 능력의 정의
"언어 능력"은 **말하기·듣기·읽기·쓰기·문자 해독**을 전부 포함한다.
- 말은 통해도 문자를 못 읽는 인물이 있을 수 있다 → 계약서, 안내문, 문자메시지 앞에서 무력해진다
- 이 격차 자체가 계층 격차이자 **타락의 통로**로 기능한다
- 언어는 그 인물의 **정체성**이기도 하다. 언어를 빼앗기는 것은 정체성을 빼앗기는 것이다

### 2.6 국적 설정의 범위
국적은 이름표가 아니다. 그 인물이 살아온 **문화, 일상 습관, 사회 구조, 법규, 종교, 언어, 문자** 전부를 포함한다.
- 무엇이 금기이고 무엇이 당연한지가 국적에 따라 달라진다
- 법적 신분(체류 자격, 신분증, 송금 구조)이 인물을 옭아매는 장치가 된다

### 2.7 의사소통 제약 (엄격히 지킬 것)
**공통 언어가 없는 인물끼리는 의사소통이 되지 않는다.**
- 편의상 통하게 만들지 않는다
- 통역자, 몸짓, 그림, 번역 앱 등 **매개**가 있어야만 뜻이 전달된다
- 그 매개를 쥔 인물이 곧 권력을 쥔다 — 오역, 누락, 왜곡이 서사의 무기가 된다

## 3. 인물 DNA 시트 양식

인물마다 아래 항목을 채운다. **외형은 얼굴·신체 등 육체적 요소만 집중적으로 강화해 적는다.
의상은 제외한다** (의상은 장면마다 바뀌므로 DNA가 아니다).

```
### [인물명] (신체 기준)
- 국적 / 민족:
- 나이 / 성별(육체):
- 계층: 부촌 / 서민촌 / 빈촌
- 언어 능력:
  - (언어명): 말하기 / 듣기 / 읽기 / 쓰기 각각의 수준
  - 문자 해독 가능 여부:
- 신분·법적 지위:
- 외형 DNA (육체 한정, 일관성 유지용):
  - 얼굴형 / 이목구비:
  - 눈:
  - 코 / 입:
  - 피부 톤 / 질감:
  - 머리카락(색·질감·길이):
  - 체형 / 키 / 골격:
  - 손·발:
  - 흉터·점·특이 신체 표식:
  - 목소리 톤:
- 성격 / 심리적 약점:
- 서사에서의 위치:
```

**외형 DNA는 소설 전체에서 절대 흔들리지 않는 고정값이다.** 장면마다 다시 참조해 묘사한다.

---

## 4. 장소 DNA 시트 양식

```
### [장소명]
- 소속 계층: 부촌 / 서민촌 / 빈촌
- 위치 / 주변 환경:
- 규모 / 구조(층수, 방 개수, 동선):
- 가구 배치 (문 기준으로 좌·우·정면에 무엇이 있는지 고정):
- 빛 / 소리 / 냄새 / 온도:
- 재질과 노후도:
- 출입 통제(누가 들어올 수 있고 누가 못 들어오는가):
- 이 장소가 가하는 심리적 압박:
```

**가구 배치는 고정값이다.** 이후 모든 장면에서 같은 배치로 묘사한다.

---

## 5. 다크 / 타락 엔딩 처리

- 구원이나 반전 회복으로 끝내지 않는다. **무너진 상태가 최종 상태다.**
- 타락은 급변이 아니라 **누적**이다. 각 단계마다 인물이 스스로 납득하는 논리를 만들어 준다.
- 마지막 장면에서 인물의 **언어**가 어떻게 되었는지 보여 준다(모국어를 잃었는지, 침묵하는지, 남의 언어로만 말하는지).
- 계층은 끝내 뒤집히지 않는다. 격차 자체가 세계의 규칙임을 결말이 확인시킨다.

---

## 6. 최종 점검 체크리스트

집필 후 아래를 전부 확인한다.

- [ ] 서구권 인물 / 서양식 이름 / 서양식 지명이 하나도 없는가
- [ ] 장면이 바뀔 때마다 `[장소]`가 붙어 있는가
- [ ] 모든 대사·독백 앞에 `이름(신체 기준)`이 붙어 있는가
- [ ] 외국어 대사에 `(번역: ...)`이 빠짐없이 병기되었는가
- [ ] 한국어 대사에 불필요한 번역이 붙어 있지 않은가
- [ ] 공통 언어가 없는 인물끼리 대화가 통해 버린 장면은 없는가
- [ ] 2개 국어 구사자가 상대와 상황에 맞게 언어를 바꿨는가
- [ ] 외형 DNA / 가구 배치가 처음과 끝까지 동일한가
- [ ] 원작 사건을 복사하지 않고 감정선 템포만 1:1로 맞췄는가
- [ ] 분량을 압축하지 않았는가
- [ ] 한 챗 안에서 완결되었는가
